FriendsLy- A Privacy-First Social Proximity and Planning Application
Introduction:
FriendsLy is a human-centered, privacy-first mobile application designed to help users become aware of nearby friends and make spontaneous plans while minimizing social pressure. Unlike traditional location-based social applications that rely on continuous GPS tracking and precise location sharing, FriendsLy prioritizes user intent, approximate proximity awareness, and transparent system suggestions.The application focuses on calm and respectful social interaction by allowing users to control their availability, visibility, and notification preferences.
Scope:
This project aims to develop a full-stack system for privacy-aware social proximity interaction. The system will offer features such as continuous proximity-based notifications, dual-radius visibility, intent selection, and explainable suggestions, allowing users to understand and control their interactions. It will not include large-scale deployment, integration with external social media platforms, or advanced predictive analytics. The primary focus is on creating a usable, ethical, and privacy-conscious system that follows human-computer interaction principles, targeting users in social settings who require awareness of and control over their proximity-based interactions.
